1. Overview

The MathML Validator is a command-line .NET application that scans a folder of EPUB files, opens each one as a ZIP archive, parses all XHTML/HTML/XML entries, and runs a configurable set of MathML structural rules against every document. Results are written as both machine-readable JSON and human-readable HTML summary pages.

Key Design Decisions

  • Rules are externally configurable via rules.txt — no recompilation needed to change which tests run.
  • A quick pre-check skips any EPUB entry that contains no MathML markup, avoiding unnecessary XML parsing.
  • If a summary HTML for an EPUB already exists, that file is skipped to avoid redundant processing.
  • Errors at any level (ZIP open, entry parse, rule execution) are captured as issue entries rather than crashing the run.
  • Rules return XElement objects, optionally wrapped in a <Context> element for richer snippet/line reporting.

4. Application Flow

5. Validation Pipeline Detail

5.1 Entry Pre-checks

Before any XML parsing, EpubValidator.ValidateEntry() performs a fast string scan:

  • If the content contains neither <math nor the MathML namespace URI, the entry is skipped immediately.
  • If XML parsing fails, an entry-parse-error issue is recorded and the entry processing stops.

5.2 Rule Return Contract

Each TestRule.Checker receives the full XDocument and returns an IEnumerable<XElement>. There are two recognised shapes:

ShapeWhen to useHow processed
<Context> wrapper element When the rule can provide richer context: a parent <Snippet> element and a child <ExactNode> element, plus optional line/column attributes. Snippet and ExactNode children are extracted; a windowed substring around ExactNode is computed for the snippet display.
Raw XElement Simple rules that return the offending element directly. SafeOuterXml() is called; line/col is sourced from IXmlLineInfo or computed via IndexOfNormalized().

6. Validation Rules Catalogue

Rules live in Tests.cs as TestRule objects inside the static TESTS list. New rules can be added by appending to this list.

math-wrong-number-of-children-2
Wrong number of children — expects exactly 2.
Targets elements: mfrac, msup, msub, mroot, mover, munder.
Flags any <math> element whose subtree contains one of these operators with only one child element instead of two.
math-wrong-number-of-children-3
Wrong number of children — expects exactly 3.
Targets elements: munderover, msubsup.
Flags any <math> element whose subtree contains one of these operators with fewer than three child elements.

Adding a New Rule

Append a new TestRule to Tests.TESTS in Tests.cs:

new TestRule {
    Id = "math-my-new-rule",
    Description = "Human-readable description of what is wrong.",
    Checker = doc => {
        XNamespace m = "http://www.w3.org/1998/Math/MathML";
        return doc.Descendants()
                  .Where(e => e.Name.LocalName == "math")
                  .Where(math => /* your condition */);
    }
},

Then add the rule ID to rules.txt to activate it, or delete rules.txt to run all rules.

8. Output Files

JSON Report (report/json/<name>.report.json)

{
  "FileName": "book.epub",
  "FilePath": "C:\\mathml_validator\\book.epub",
  "Issues": [
    {
      "EntryPath": "OEBPS/chapter1.xhtml",
      "TestId": "math-wrong-number-of-children-2",
      "TestDesc": "Wrong number of children. There should be two children.",
      "Snippet": "<math><mfrac><mn>1</mn></mfrac></math>",
      "ExactNode": "<mfrac><mn>1</mn></mfrac>",
      "Line": 42,
      "Column": 8
    }
  ]
}

HTML Summary (report/html/<name>_summary.html)

  • Self-contained HTML with embedded CSS — no external dependencies.
  • Issues grouped by rule ID, showing occurrence count in the header.
  • Each occurrence shows: entry path, line/column, a collapsible code snippet, and the exact offending node highlighted in a red border.
  • xmlns declarations are stripped from snippets to reduce visual clutter.

9. XmlHelpers Reference

MethodSignaturePurpose
SafeOuterXml (XElement el, int maxLen=600) → string Serializes an element to a compact single-line string; returns "" safely on null/exception.
GetContextFromParent (XElement parent, string childOuter) → string Returns a windowed substring of the parent XML centered on the child element; falls back gracefully.
TruncateCollapseWhitespace (string s, int max=600) → string Collapses whitespace runs to single spaces, truncates to max chars, appends … if cut.
IndexOfNormalized (string haystack, string needle) → int Finds needle in haystack after normalising all whitespace in both strings.
GetLineColumnFromOffset (string text, int offset, out int line, out int col) Converts a character offset into 1-based line and column numbers by scanning lines.
